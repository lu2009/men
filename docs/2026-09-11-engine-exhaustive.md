## 0. 方法与可信度

### 0.1 两条铁律（本轮再次踩到，务必遵守）

1. **统计赋值点必须同时覆盖 `.x=` 与 `["x"]=` / `[accessor(N)]=` 三种形态。**
   本轮实例：B平 的 `doorsheet` 是 `_0x551a25.doorsheet=`（**点号**，@490575），而 A/B吊/D/C 都是 `[t(975)]=`。
   只扫方括号形态会得出「B平 没有 doorsheet」的错误结论。
2. **同一个数字索引在两张串表里含义不同。**
   本轮实例：`(556)` 在 `_0x1260`（前段组件，accessor `_0x4017e5`/`x`）里是 `style`，在 `_0x43b0d8`（打印主逻辑）里是 `扣板厚1`。
   凡本文件引用 token 值，均已确认所在区间的 accessor 属于 `_0x43b0d8` 别名链
   （`_0x59f9e4` / `_0x11f592` / `_0x5c0d14` / `_0x34750c` / `_0x2938b1` / `_0x46841d` / `_0x2b3230` / `_0x1add4e` / `_0x38081a` / `_0x15e237`）。
   未确认处一律写「未确定」。

1. **`hinge` 只在 6 个平开引擎里计算并施加**；全部 6 个吊趟引擎**完全不读 `hinge`**（证据：`(481){hinge}` 仅 @379058/L平、@413124/G平、@484182/B平、@525067/D平；字面量 `.hinge` 仅 @458358/A平、@563117/P1平；吊趟 setup 里连 `五金` 都不读——`五金` 只在 remark 段出现）。
