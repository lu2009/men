## 0. 一页结论

**QL 与底座 `docsheet/` 的重合面比 PS 还小。** §ps §0.1 已证明 PS「CSS/HTML/分页/清洗四块没有一行能共用」；
QL 在此基础上**再多丢两块**：① 底座整套 `paginate.ts`（量测 iframe / 行高预算 / 打包）对 QL **完全无对象**——
QL 没有分页；② 底座的 `DocSheetClasses`（`{ns}-title` / `{ns}-table` / `{ns}-line` / `{ns}-page-num` …）
一个都不出现，QL 产出 HTML 的 class 只有 **4 个**：`qlabel-root` / `qlabel` / `qfield` / `qfield-qr`|`qfield-text`。

### 0.1 逐段判定（这就是「底座要加哪些参数」的答案）

| 底座文件 | QL 能不能用 | 判定依据 |
|---|---|---|
| `types.ts` `PaperConfig` | ❌ **表达不了** | QL 的 `paper` 多 `printRotate90`；且 `orientation` 在 QL **不是死字段**（`printSilent` 的 `landscape` 读它，`QL:1006`），而底座注释把 `orientation` 标成「有字段、无消费者」 |
| `types.ts` `PrintConfig` | ✅ **逐字可用** | QL 的 `print` 只有 `{copies}`（`QL:203`），与底座同 |
| `profile.ts` `DocSheetProfile` | ❌ **表达不了** | 缺 `fields[]` / `globalFont` / `autoHideEmpty` / `printRotate90`；`cellCases` 的「列 key → 3 形态」模型对不上「自由定位字段 + 每字段 11 个属性」。**QL 要另起一个 profile 接口**（§10.2） |
| `profile.ts` `DocSheetClasses` | ❌ **派生规则不成立** | `createDocSheetClasses('ql')` 给出 `ql2-title`/`ql2-table`/`ql2-line`…，QL 一个都不吐（§4.1） |
| `html.ts` `escapeHtml` | ✅ **逐字相同，直接用** | `QL:625-630` 与 GS:182-187 / PS2:191-196 的 5 条 `replace` 完全一致（`&`→`<`→`>`→`"`→`'`，顺序同） |
| `html.ts` 其余（`renderMultiline`/`renderCell`/`renderRow`/`renderPage`/`renderTableHead`/`buildRootHtml`/`renderPreviewTable`/`buildDocumentHtml`） | ❌ **零复用** | QL 无 `{ns}-line`、无表格、无标题/页码、无「无可见列」占位。⚠️ 特别地：**QL 不认 `<br>`** —— 它把整串转义（`QL:625-630`），`备注:加急<br>加配:X` 会**逐字显示 `<br>`**（§4.2，样本 `ql-sample.html` 第 1 张标签 `data-key="remark"` 可见 `&lt;br&gt;`）。底座 `renderMultiline` 的按 `<br>` 切行**在 QL 是错的** |
| `paginate.ts` **全部**（`paginate` / `measureRowHeights` / `buildMeasureTable` / `PAGE_BUDGET_*` / `FALLBACK_ROW_HEIGHT_MM` / `renderAllPages` / `buildDocSheetHtml` / `buildDocSheetDocument`） | ❌ **零复用** | QL **没有分页**：`ae()`（`QL:719-767`）一次产出**全部**标签，`page-break-after:always` 交给浏览器（§5.1）。`ae` 全文 **0 个 `await`**（CONFIRMED：`sed -n '719,767p' \| grep await` 空），是纯同步拼串 |
| `paginate.ts` `waitForImages` | ✅ **可直接用** | `QL:956-969` 与 GS:493-506 逐字同构（`complete` / `onload` / `onerror`，**无超时**） |
| `paginate.ts` `MEASURE_IMAGE_TIMEOUT_MS` | ⚠️ **语义可用，值要新定** | 它只服务于「量测」；QL 的量测那条链路**不存在**。但 `print.ts` 已把它当**打印**兜底复用（`print.ts` 注释），QL 的 `printDirect` 同样可以吃这个兜底 —— 这是新版对旧版缺陷的既有修复，**两处一致** |
| `css.ts` `docSheetCss` | ❌ **必须新写** | QL 的 CSS 是 **838 字符 / 11 条规则**（默认 70×90 无旋转），底座是 1739 / 23 条；**本家族唯一有 `@media print` 旋转分支**（§4.3） |
| `qr.ts` `createQrEncoder` | ⚠️ **要用，但回退常量不同** | QL 与 GS2/PS2 的编码器语义逐字相同（`MARGIN=1`、缓存键 `text+"::m1"`、失败返回 null），**但 QL 自己带一层缓存 + 回退 `"0 0 200 200"`**，且 `write(text,200,200)`（§4.2）。底座的 `createQrSvgProvider` 回退是 `'0 0 180 180'` |
| `sanitize.ts` **全部** | ❌ **必须新写** | schema 完全不同，且 QL 的 `N` 在**读盘与写回两端都调用**（§骨架 §1.3 / §2.2；QL 的「保存设置」`k` 和「保存布局」`oe` 都跑 `N`）。**QL 的额外一条：全字段不可见时整体回落默认**（§2.6 R11） |
| `storage.ts` `loadDocSheetSettingsWith` | ⚠️ **要扩 2 个键** | QL 有 **4 个** localStorage 键（§骨架 §8.1）：模板 / 打印机 / 固定标签数开关 / 固定标签数。前两个形状同底座，后两个是**裸字符串**（`"1"`/`"0"` 与数字串），需要新函数 |
| `storage.ts` `saveDocSheetConfigByKey` / `saveDocSheetPrinterByKey` | ✅ **可直接用** | `QL:235-240`（`M`）/ `QL:369-374`（`E`）与 GS/PS2 逐字同构（空 `try{}catch{}`、打印机存裸串） |
| `print.ts` `printHtmlViaIframe` | ⚠️ **骨架可用，iframe 样式必须参数化** | QL 的 iframe 是 **`top:-9999px;left:-9999px;width:{widthMm}mm;height:{heightMm}mm`**（`QL:943-947`），底座的 `PRINT_IFRAME_STYLE` 是 `top:0;left:0;width:0;height:0`（§骨架 §5.1 已把这条列为四张里唯一结构性差异）。其余（等图 / **300ms** / focus+print / **1000ms** 摘除）逐字相同 |
| `print.ts` `printDocSheetDirect` | ❌ **不适用** | 入参形状是 `(rows, config, opts, profile)` 且内部走 `buildDocSheetDocument`；QL 的文档构造是 `de()`（head 多一段 `<style>`，§4.4），**要另写** |

**复用统计：可原样用的只有 `escapeHtml`、`waitForImages`、`saveDocSheetConfigByKey`、`saveDocSheetPrinterByKey` 四处；
要参数化的 4 处（QR 回退 viewBox、iframe 样式、文档模板、存储键集）；其余全须新写。**

### 3.3 「整体自适应」`j()`（`QL:459-478`）—— 不是「按当前版式缩放」

```js
const u = a();               // ← 基准恒为【默认配置】的 70×90 版式，不是当前字段
const r = t / 70, i = o / 90, c = Math.min(r, i);
e.forEach(field => {
  const l = u.fields.find(l => l.key === field.key);   // 从默认版式取基准
  if (!l) return;
  field.x     = round(l.x * r * 10) / 10;              // 非等比
  field.y     = round(l.y * i * 10) / 10;              // 非等比
  field.width = round(l.width * r * 10) / 10;          // 非等比
  if (field.key === 'qrcode') { field.width = round(l.width*c*10)/10; field.height = field.width; }
  else field.height = l.height;                        // ← 不缩放，直接抄默认
```
