开门红 · 订单财务

财务管理使用手册

订单列表右侧滑出来的那个面板 —— 收款、抹零、预付款、对账都在这儿做。 这份手册先说清三个最容易搞混的数字，再讲每个按钮点下去会发生什么。

01从哪儿打开

订单管理页 → 找到那一行订单 → 操作列点 财务。 面板从右边滑出来，标题是「财务管理 — 客户名」，里面三个标签页。

面板里的所有操作都只对当前这张单（或当前这个客户）生效， 换订单要关掉重开。

02先分清三个数

绝大多数「数字对不上」的困惑，都出在这三个数被混着看。 它们各管一件事，范围不同——第一个只管一张单，后两个管整个客户。

一张单
本单未收
这一张单还差多少钱没收到。
收满了它就是 0，永远不会是负数。
一个客户 · 欠款
客户余额
这个客户名下所有单加起来还欠多少。
它是欠款，所以也是 0 起、不会为负。多付的钱不体现在这儿。
一个客户 · 余钱
未分配余额
客户已经打给我们、但还没算到任何一张单上的钱。
相当于客户在我们这儿的余额。
最容易搞混

「客户余额」是欠款，「未分配余额」是余钱，方向正好相反。 一个人可以同时「欠我们 2400」又「在我们这儿存着 7500」—— 这两个数会同时显示，不互相抵消。

拿一个例子走一遍

张老板有两张单：A 单 3200 元、B 单 1800 元。他先往我们这儿打了 10000 元， 我们把这个钱里的 2500 元分到 A 单上，A 单又给他抹零 100 元。

A 单 · 已分配
2500.00
A 单 · 订单调整（抹零）
100.00
A 单 · 本单未收
600.00
B 单 · 本单未收
1800.00
客户余额（还欠）
2400.00
未分配余额（余钱）
7500.00
实收金额（累计充值）
10000.00

算一遍就明白：本单未收 = 3200 − 2500 − 100 = 600； 客户余额 = 600 + 1800 = 2400； 未分配余额 = 10000 − 2500 = 7500。

03三个标签页

📄 本单财务 —— 看这一张单的账

顶部横幅一眼看到回执单号、订单总价、本单未收（未收不为 0 时标红）。下面四张卡：

卡片是什么
订单总价这张单的合同金额
已分配金额已经算到这张单上的钱（本单收款 + 从客户池子分过来的）
订单调整金额这张单的抹零 / 优惠 / 补贴 / 冲销合计
未收金额总价 − 已分配 − 订单调整，最小为 0

再往下依次是：收款分配记录 → 本单收款表单 → 订单调整记录。

本单收款表单填「收款金额 / 收款日期 / 收款方式 / 备注」，金额精确到分。 打开 预付优惠 开关后可以填优惠比例（0.1%–99%）， 旁边会实时显示「预计抵扣 ¥多少」。填完点 收款。

这个抵扣额按 收款金额 × 优惠比例 算。 它有一个前提：收款金额 + 抵扣额 不能超过这张单的未收 —— 也就是说收满这张单时用不了优惠（没有可减的了）， 系统会提示你。那种情况把开关关掉即可。

表单下面那颗 订单抹零 / 冲销 按钮，打开第 4 节的弹窗。

💰 客户收款 —— 管这个客户的钱

最上面一张紫卡是客户的四个总账数字：订单总额 / 已实收 / 客户余额 / 未分配余额。

录收款是这一页的主功能，步骤是「先预览、再提交」：

  • 填收款金额、日期、方式、备注
  • 点 预览分配 —— 系统按订单日期从早到晚把钱自动铺到欠款的单上，给你看一份方案
  • 确认无误后点 提交收款。没预览过就提交，系统会拦住你

预览表下面有一行「剩余未分配」：这笔钱铺完所有欠款单之后还剩多少 —— 剩下的部分会留在客户池子里，变成「未分配余额」。

最下面「其他操作」三颗按钮：客户抹零 / 冲销 · 录入预付款 · 预付款分配。

📊 客户对账 —— 回头看账

  • 收款趋势：按月一根双色条，绿色是收进来的、红色是红冲掉的
  • 对账明细：按日期倒序列出每一笔（收款 / 红冲 / 订单抹零 / 客户抹零）， 可以按类型下拉筛选，也可以在关键字框里搜单据号、日期、地址、备注

04四个弹窗

弹窗填什么管什么
订单抹零 / 冲销 调整金额 · 调整类型 · 备注 只影响这一张单。类型：抹零 / 优惠 / 补贴 / 冲销 / 其他。
正数 = 少收（抹掉欠款），负数 = 冲销（把之前多抹的加回来）
客户抹零 / 冲销 调整金额 · 调整类型 · 备注 挂在客户名下，不落到任何单上，只减「客户余额」。
类型：月度抹零 / 优惠 / 冲销 / 其他。一般在月底整批抹零时用
录入预付款 收款金额 · 日期 · 方式 · 备注 · 冲销开关 客户先打钱放着、还没指定抵哪张单时用这个。钱进「未分配余额」。
打开 冲销 开关可以把钱从池子里扣回去（金额填正数）
预付款分配 分配金额 · 优惠比例 把池子里的钱分到具体订单上。点 预览分配方案 看方案， 再点 执行分配 落库。没预览过不能执行
两个抹零的区别

订单抹零冲的是某一张单的欠款（这张单的「本单未收」会变小）； 客户抹零冲的是客户整体（各单未收不变，只有「客户余额」变小）。 算总账时两者都会减，但看单张单的时候只有订单抹零有用。

05常见情况怎么做

客户交一笔钱，要抵掉几张单

  1. 打开「💰 客户收款」，填收款金额、日期、方式
  2. 点 预览分配，看系统打算怎么分（按订单日期从早到晚）
  3. 方案不对就先别提交 —— 要么改金额，要么先去做别的操作调整欠款分布
  4. 确认后点 提交收款

客户事先打了一笔钱放着，以后再用

  1. 「💰 客户收款」→ 录入预付款，填金额和日期
  2. 钱进「未分配余额」，此时不影响任何单的未收
  3. 以后要用时 → 预付款分配，填分配金额，预览后执行

客户少给了几十块，不打算要了

  1. 如果是某一张单的事：「📄 本单财务」→ 订单抹零 / 冲销
  2. 如果是整个客户年底一起抹：「💰 客户收款」→ 客户抹零 / 冲销
  3. 金额填正数（比如 50），类型选抹零

收错了 / 录错了，要退回去

  1. 收款录错：在「📄 本单财务」的本单收款里，金额填负数（比如 −500 红冲掉 500）
  2. 抹零抹错：「订单抹零 / 冲销」或「客户抹零 / 冲销」，金额填负数
  3. 预付款录错：「录入预付款」打开冲销开关

订单整张删掉了

删订单在订单列表页做（选中 → 删除），不在这个面板里。 删除时如果有财务记录，系统会自动红冲：本单收款和订单抹零各冲一笔， 从客户池子分过来的钱则退回池子。确认框里会列出来让你看清楚再删。

06每个数怎么算出来

对账对不上时照这张表逐个核。

数字怎么算的
本单未收 订单总价 − 本单收款 − 池分配 − 订单调整
结果小于 0 就按 0 算
已分配金额 本单收款 + 从客户池子分到这张单上的钱
客户余额 各单未收加起来 − 客户抹零合计
结果小于 0 就按 0 算；这是欠款，不含余钱
未分配余额 客户打进来的钱（净额） − 已经分配到订单上的钱
实收金额 客户打进池子的钱里所有正数相加
红冲不减它 —— 它是「累计充值」不是「净收款」
订单总额 各单的（已分配 + 未收 + 订单调整）相加
预付优惠（本单收款） 收款金额 × 优惠比例
前提：收款金额 + 抵扣额 ≤ 本单未收
预付优惠（预付款分配） 分配额 × 优惠比例，再取「不超过这单剩余未减部分」
所以整单被付清时它是 0
订单调整合计 所有订单抹零 / 优惠 / 补贴 / 冲销相加
客户调整合计 所有客户抹零 / 优惠 / 冲销相加
为什么「实收金额」看着不对

一位客户打进来 1000，后来红冲掉 1000 —— 实收金额还是 1000，未分配余额变成 0。 这不是错。实收金额记的是「这位客户总共往我们这儿打过多少钱」， 减钱这件事体现在「未分配余额」上。

07六条不能忘的规矩

  • 1未收永远不会是负数。多收了、多抹了，系统会按 0 截住，不会出现「客户倒欠」这种账。
  • 2池子里有多少，才能分多少。申请分配 100000 但池子只有 2000，实际只会按 2000 处理，不会把池子扣成负数。
  • 3收满的单没有优惠。预付款分配时，优惠按「分配额 × 比例」算，且不会超过这单剩下没减完的部分 —— 所以被一次付清的单优惠恒为 0。本单收款时，如果收款额加抵扣额超过了未收，系统会直接拦下不让你提交。
  • 4优惠是店里让利，不动客户的钱。不管在本单收款还是在预付款分配里给优惠，客户池子里的钱一分不少，只是这张单少收那么多 —— 优惠会单独记一条「订单调整」。
  • 5收款不能超过欠款。本单收款不能超过这张单的未收；客户级操作不能超过客户还欠的总额。
  • 6红冲用负数。录错了不要想着「再录一笔抵掉」—— 直接在原处填负数，账面上才留得下痕迹。

08对不上账时怎么办

  1. 先确认你看的是哪个数 —— 是一张单的未收，还是客户的余额？（第 2 节）
  2. 打开「📊 客户对账」，按日期倒序看每一笔，找出让你意外的那条
  3. 拿第 6 节的公式手算一遍，看和界面差多少
  4. 差的钱如果正好等于某笔抹零 / 优惠 —— 那就是理解口径的问题，不是账错
  5. 确认真的记错了：按第 5 节「收错了要退回去」用负数红冲，不要直接改数据库
注意

这套账的设计是只加不改：任何一笔操作都会留下一条记录，永远不覆盖历史。 所以「改数字」这件事在系统里不存在 —— 只有「再记一笔反向的」。 这也是为什么对账明细里能看到全部来龙去脉。

这份手册描述的是当前版本的实际行为。文中所有公式都与系统逐条核对过， 并用手工算例验证过结果一致。如果界面上看到的数和手册不符，请以手册第 6 节的公式为准排查。
