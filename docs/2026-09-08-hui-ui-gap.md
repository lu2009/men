# Hui 页「布局 / 交互」差异逐项清单（对照旧版还原）

> 依据：旧版 `legacy/js/Hui.formatted.js`（平开组件 `_0x5a7707`、吊趟组件 `_0x4d18bf`、主页面 `_0x3c40f9` 的 DOM/UX 反推）+ `docs/2026-08-23-hui-analysis.md`。
> 说明：本清单只管**页面长什么样、怎么操作**；数据/计价/校验等逻辑层已在 #1–#8 完成，不在本表（涉及处会标注“逻辑已对齐，仅呈现待改”）。

---

## 0. 总评

| 层 | 还原度 | 说明 |
|---|---|---|
| 业务逻辑（算料/计价/校验/保存/单行接口） | 高 | #1–#8，真实浏览器点验 |
| **页面骨架与观感** | **低** | 旧版=顶栏命令按钮 + 整页**两张就地编辑的密集表格上下并列**（开关显隐）；新版=卡片 + **两个 tab** + 只读行表 + **右侧抽屉编辑** |
| **行内编辑交互** | **低** | 旧版行内直接点格子改、随输随算、列内控件与图；新版要点“编辑”→抽屉→确定 |
| 行内可见资产（开向图/门花图/3D/加价项就近） | 缺 | 多数是此前后置项，本次提上来 |

**根因**：旧版把「订单=两张 Excel 式就地编辑表」；新版把它做成了「列表 + 表单弹层」。要还原观感，核心是把 `/hui` 重做成**就地编辑的密集表格 + 命令按钮行 + 门类开关**，而不是 tab + 抽屉。

## 1. 顶层骨架差异

### 旧版主页面（`_0x3c40f9`）
| 区 | 旧版 | 当前新版 |
|---|---|---|
| 顶按钮行 | `1.清空` `2.添加门类` `3.保存回执单` `3D画图` `刷新` `视频` | `新建订单 / 新增平开门 / 新增吊趟门 / 保存订单 / 订单列表 / 回执单预览 / 终端链接 / 标签打印 / 玻璃合片单` |
| 客户/订单头行 | 客户(搜索)、电话、安装地址、备注、业务员、生产天数、订金(元)、品牌 + 只读「日期」「编号(回执单号)」 | 客户(下拉)、电话、品牌、日期、生产天数、回执单号、定金、业务员、订单备注（多一个汇总条/截止日期/门数/总价/余款） |
| 门类切换 | 无 tab：两表并列，靠「添加门类」抽屉里的 平开门/移门 按钮各自 toggle（可同显） | 两个 tab（平开/吊趟）互斥 |
| 表形态 | 平开一张 el-table、吊趟一张 el-table，密集、`size=small`、就地编辑 | 每类一张只读 n-data-table，编辑走抽屉 |
| 底部 | 每张表下方「＋添加行」按钮 | 无（新增在顶栏/抽屉里） |
| 汇总落点 | 头部只见 日期+编号；截止/总价/门数/余款在保存后进**回执单预览** | 头部实时汇总条 |

**建议改法**：顶部改为命令按钮行（保留/合并现有功能入口，按旧版次序排）；头部字段改为一条**就地编辑表单行**（客户搜索框+电话+安装地址+备注+业务员+生产天数+订金+品牌+只读日期/单号）；移除 tab，改两张可独立显隐的表（空态显示“添加门类/平开门 移门”引导）；汇总条改造（回执单预览承接截止/总价/门数/余款）。「订单列表/终端/打印」这类高级入口可收到次级菜单或抽屉，不占主行。

## 2. 表格列 / 行形态差异（观感最大项）

### 旧版列（两张表列序，含就地控件）
- **平开门**（约 20 可见列，表头已按语义归组显示，实际仍平铺）：操作列(复选/删除/复制/查看3D) · 门花图(缩略/点击传图/文字传图/算料) · 型材/颜色 · 单价/数量 · 玻璃(面玻/底玻/厚度) · 开向(包边/锁具/开向+开向图) · 门洞尺寸(宽/高/墙厚/亮窗/洞尺) · 吊脚 · 亮窗总高 · 五金 · 封板高 · 备注(地址+备注) · 金额(金额+平方，平方可右键改) · 加价项目(点添加+多选+明细) · 计价方式 · 打折 · 前/后包加长 · 单/双丁墙体 · 单号（部分列按租户 `columnVisibility` 显隐）
- **吊趟/移门**：操作列(复选/删除/复制/查看3D) · 门花图 · 型材/颜色 · 单价/数量/套线单价 · 玻璃 · 扇数/开向(+行内开向图) · 下轨道/套线 · 门洞尺寸(高/宽/墙厚/洞尺) · 亮窗信息(总高/数量/封板高) · 五金(tag) · 备注 · 金额(金额+平方) · 加价项目 · 上轨/边封(轨道长/边封数) · 前包/后包 · 单双丁 · 计价方式 · 打折 · 单号

### 当前新版
- 两 tab 内一张窄只读表：型材/颜色/开向/尺寸/平方/数量/单价/计价/金额/备注 + 编辑/删除（吊趟多 扇数）。
- 绝大多数字段被收进 640px 右侧抽屉（两列网格）。

**建议改法（P0）**：把整行字段放进**行内可编辑控件**（输入/下拉），仿旧版“单元格就地编辑”，随输随算；表头语义分组可用列分组或表头合并近似还原；按门型保留各自的列集与默认（diao 有 扇数/套线单价/边封数/轨道长…）。优先保证「能直接在表里改完全部字段」这一主交互成立，列数量与顺序对齐旧版。

## 3. 交互流差异

| 交互 | 旧版 | 当前新版 | 改法 |
|---|---|---|---|
| 新增行 | 表下方「＋添加行」：**就地 push 一行默认空行**（继承上一行回执单号/客户，diao 默认 扇数 2轨2扇/边封2/计价方/底玻记忆/面玻白玻） | 顶栏「新增X门」→抽屉→确定才出现行 | 改成每表底部添加行按钮就地加行；抽屉改用于高级/批量编辑（或保留编辑抽屉但主交互行内化） |
| 就地改 | 点格子直接改，deep watch 即时重算 平方/套线金额/金额/加价 | 改抽屉内字段→确定→才重算行 | 行内 v-model + watch 即时重算（逻辑已具备，迁移到行内即可） |
| 保存 | 整单「3.保存回执单」；前置校验链+标红行字段+剔除全空行；自动回填单号/业务员/安装地址/formulaid | 「保存订单」同逻辑（消息列表列缺字段） | 基本一致；把“标红缺字段单元格 + 停在对应行”的可视反馈补上 |
| 删除行 | 三重：验密码→“确定要删除这一行吗？”→已录单再弹“该单已经录入成功…永久删除”→deleteRow | 一重 dialog | 加“已录单永久删除”二段确认；验密码层可选（对 admin） |
| 复制行 | 操作列「复制」就地 push（清 生产进度/单号/图片/isSelected） | 无 | 加行操作「复制」 |
| 查看3D | 行内「查看3D」→页内全屏 3D overlay（前置校验 尺寸/扇数开向） | 无（#8 后置） | 本次提上来（见 §4） |
| 门花图/开向图 | 行内缩略 + 点击预览/传图/文字传图；开向图随 扇数+开向 就地显示 | 无 | 本次提上来（见 §4） |
| 加价项目 | 行内「点击添加」+多选+明细行（\n 逐行）；另「加价项目管理/自动加价设置」入口 | 抽屉内编辑列表 | 行内多选+明细；项目管理入口~~收进菜单~~ → **2026-09-19 归位**：仍留在**「添加门类」抽屉**第 4/5 项（旧版它就在那儿，见 `docs/2026-09-19-hui-shell-audit.md` §8.6） |
| 平方数 | 行内只读 + **右键弹「修改平方数」** | 抽屉里可改 | 保留行内右键改平方 |
| 未保存离开 | onBeforeRouteLeave / beforeunload 拦截 | ~~有草稿持久化~~ + 有离开拦截（两样都有了） | ✅ 已齐 |
| 密码验证 | 删除/财务等走 verifyPassword | 无 | 按需补（admin 可简） |

## 4. 本次要“提上来”的后置项

| 项 | 旧版形态 | 本次工作量评估 | 备注 |
|---|---|---|---|
| 开向示意图 | 扇数+开向组合合法即**行内显示图片**（`directionImageMap`），纯展示 | 中 | 需把旧版方向图资源从 legacy chunk（10-5_5-front / 1_right 等）抽成图片资源 + key→图 映射（`directionImageMap` 已反推键结构，值在图资源里） |

## 5. 建议分期（确认后按此执行）

- **A（骨架+主交互，最大感知项）**：顶按钮行 + 头部就地表单行 + 去 tab 改两表并列开关 + **行内就地编辑/随输随算** + 每表底部「添加行」/复制/删除(二段确认)/整单保存标红反馈 + 加价项目行内多选明细 + 平方右键。列集/列序对齐旧版。
- **B（本批后置项）**：开向示意图资源映射 + 门花图(IndexedDB 上传/文字传图/预览)。
- **C（单独大件）**：3D 视图 overlay / 顶层 3D 画图路由 —— 依赖 legacy 3D 场景与模型资源迁移，量级最大，建议单独立项评估。
