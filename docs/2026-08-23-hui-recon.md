# 汇算页（Hui）精确实现附录（反混淆提取）

> 本文是 `docs/2026-08-23-hui-analysis.md` 的补充，沉淀从 `legacy/js/Hui.formatted.js` 反混淆提取的**精确代码/参数**，供后续 Phase B3（玻璃计算+标签数量）、Phase C（取价/公式匹配）、Phase F（hiprint 打印）落地时直接引用，避免重新反混淆。

## 1. 取价接口精确参数（Phase C）

| 动作 | 方法 | 参数 | 返回 `data` |
|---|---|---|---|
| `getDiaoPrice` | GET | param2=ds, param3=型材, param4=客户 | `{单价, 套线单价}` |
| `getPingPrice` | GET/POST | param2=ds, param3=型材(+lock+formulaid+file+registrant 若轨道种类) , param4=客户 | `{单价, 计价方式, lock[]}` |
| `getDiaoFormulas` | POST | param2=registrant, param3=ds, body `{formula:[formulaid...], id:[rowId...]}` | `{formulas:{formulaid→obj}, orderNumbers:{rowId→单号}}` |
| `initializPing` | GET/POST | param2=registrant | `{material, square, formulaType, hingeNames}` |
| `initializDiao` | GET/POST | param2=registrant | `{material, trackType, lineType, square}` |

- 单价取回后写入行 `单价`/`计价方式`/`套线单价`；`lock[]` 是锁定条件数组（存 `profile_prices.lock_rules`）。
- 公式匹配：前端把行（型材/扇数/开向…）组织成 `formula`/`id` 数组发给 `getDiaoFormulas`，服务端返回每行的公式对象（`formulaid`）与关联单号。

## 2. 玻璃计算（`calculateGlass`，Phase B3/F，模式 1 玻璃合片单）

输入：行的算料部件（含玻璃部件，`quantity` 为单樘玻璃张数）、`底玻`/`面玻`、公式类型。

```
单玻判定 full = ("无" !== 底玻 || "无" === 面玻 || name.includes("单玻"))
            && ("无" !== 面玻 || "无" === 底玻 || name.includes("单玻"))
count = full
        ? part.quantity × 数量         // 双玻全量；公式类型 parentSubsidiary → 4 × 数量
        : part.quantity / 2 × 数量     // 单玻减半；parentSubsidiary → 2 × 数量
公式类型 diamond（钻石型） → count = 3 × 数量   // 覆盖上式，不分单双玻
```

- 「无」= 单玻（底玻/面玻恰一为「无」即单玻，双玻两者皆非「无」）。
- 玻璃宽/高沿用算料行 `result`，不重算。

## 3. 标签数量（`lable`，Phase B3/F，模式 4/10/11）

标签字段：`qrcode/client/door/size/color/lockway/remark/orderID/address/glass/package/storeAddress`。

**平开门 ping**：
```
t = 数量 × ping_tabs.sheets
if 亮窗总高>0  t += ping_tabs.add
if 墙厚>0      t += ping_tabs.add_2
if 型材含"钻石" t = 4 × 数量
```

**吊趟/移门 diao**：
```
t = 数量 × (扇数N × diao_tabs.sheets + 1)
if 亮窗总高>0  t += diao_tabs.add
if 套线单价>0  t += diao_tabs.add_2
// 工厂特判（registrant 匹配）：
名甸门业/旺达名门/名扬门业/临泉县品匠移门 → t -= 1
宏叶芯诚 → t += 3
美居门业有限公司 → t = 1
折叠N扇 且 鑫隆迪门厂 → t = 1
// 型材特判：
型材含"哑口套"/"门套" → t = 数量
型材含"+0" → t -= 1
```

扇数 N 提取（`fans` → N）：单轨单扇=1、单轨2扇/2轨2扇/一固一活/双活=2、2轨3扇/3轨3扇/3轨2扇1纱=3、2轨4扇/4轨4扇=4、5轨5扇=5、6轨6扇/3轨6扇/3轨4扇2纱=6、7轨7扇=7、折叠2–9扇=2–9。

> `ping_tabs`/`diao_tabs`（`{sheets, add, add_2}`）是租户配置表；工厂特判依赖 `registrant`（租户名）。落地时先以默认配置 `{sheets:1, add:0, add_2:0}` 计算，配置表接入后替换。

## 4. 打印模板获取（Phase F）

- 模板**服务端下发**：`getTemplates?param2=registrant` 返回 hiprint 模板 JSON，按名取 `product/product2/product3/product4/product10/glass/glassHole/lable/receipt/FinalReceipt/ReceiptList/sale`。**仅 `sale` 模板内嵌前端**，其余均从服务端取 → 落库 `print_templates`（已建表）。
- 纸张：模板名含 `lable` → 70×90 竖版；其余 A4（297×210）横版。
- 打印通道：本地 `localhost:17521`（namespace `hiprint-smartdoor-<ds+1088>`），云打印 `v4.printjs.cn:17521`（socket.io，namespace 同）。

## 5. 扇数/开向自动推导（前端取价前）

- 型材关键字 → 扇数：`2+0`→3轨3扇、`3+0`→4轨4扇、`4+0`→5轨5扇、`5+0`→6轨6扇、`6+0`→7轨7扇。
- 型材含「哑口套」「口套」→ 单价 0、底玻/面玻「无」、玻璃厚 8、轨道「无」、开向「无」、套线「双包」。
