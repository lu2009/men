### 1.3 平开表差异
1. 操作列：旧版有 **复选框(批量)** 与 **查看3D**；我们无（3D 已定后置）；多一个「编辑」入口。
   📌 2026-09-19：本条已复核 —— 查看3D 按 3D 暂缓不补；原先顶在那儿的「算料」**位置错了**，已挪回门花图列，见文首「补记」。
2. **缺列**：五金、封板高、前包加长、后包加长、单/双丁墙体、单号 —— 全部要进抽屉，未行内。
3. 旧版「开向」一格内嵌 包边/锁具/开向+图；我们拆成 轨道/套线种类/包边/开向 四列 → 更宽更疏。
4. 单价/数量、金额+平方 旧版**同格两控件**，我们拆列。
5. 密度：旧版格子 padding 1px、窄列、一屏几十列；我们列宽大、输入框 padding 大 → 明显更“空”。
6. 校验表现：旧版缺必填字段**单元格红框 error-cell**；我们只弹消息。
7. 已录行删除：旧版“验密码→确认→已录单再确认→deleteRow”；我们只有“已录单二段确认”。
8. 加价：旧版行内多选下拉 + 明细多行 +「加价项目管理/自动加价设置」入口；我们是摘要按钮+抽屉逐条。

## 3. 观感差异主因（优先级排序）

| 优先级 | 差异 | 影响 |
|---|---|---|
| 高 | **密度与“一格多控件”布局**（单元格 padding 1px、多个子控件挤一列、窄列宽）：旧版一张表 20+ 列紧凑；我们宽而疏 | 决定“像不像表格” |
| 高 | **组合列没还原**：单价/数量、金额+平方、开向内嵌包边/锁具 | 结构骨架不同 |
| 中 | **缺列未行内**：五金/封板高/单双丁/前包后包/单号/洞尺（仍需抽屉） | 行内覆盖率不足 |
| 中 | 操作列：复选框(批量)、查看3D(后置)；删除/复制布局 | 交互差 | ~~2026-09-19 已复核：查看3D 属 3D 暂缓；算料位置已修正~~ |
| 中 | 校验标红单元格、验密码、未保存行高亮 | 状态反馈 |
| 中 | 加价项目多选+明细多行、「加价项目管理/自动加价设置」入口 | 功能入口差异 |
| 低 | 列顺序、默认枚举（玻璃厚 4,8,5,6,10,12,0 等）、列宽自适应 | 细节 |

> 注：移门组合开向示意图（旧版动态绘制）与 3D 同属 C 期，本表未计入“可直接修”范围；其余差异都是可在现有行内网格上继续对齐的。
